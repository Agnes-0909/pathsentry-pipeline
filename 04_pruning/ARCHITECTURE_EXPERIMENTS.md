# P02 分割头结构实验

H1、H2 各自从 P01-B1 初始化，只改分割头并冻结检测网络。检测输入、训练数据、Copy-Paste、分割损失和验证集不变；速度是相同脚本、同一 GPU 会话中的配对测量中位数。

| 模型 | 状态 | 最佳/已训练 epoch | 参数量 | GMACs | mAP50-95 | person AP | 分割 IoU | 延迟 ms |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| B1 | 基线 | - | 10,003,415 | 31.89 | 0.1145 | 0.0184 | 0.9942 | 3.50 |
| H1 | complete | 17 | 9,605,399 | 24.04 | 0.1145 | 0.0184 | 0.9947 | 3.16 |
| H2 | complete | 14 | 9,839,191 | 23.68 | 0.1145 | 0.0184 | 0.9944 | 3.01 |

H1：P2/P3/P4/P5 融合宽度 128→64，按训练后通道分数迁移权重。H2：移除 P2 lateral 和最高分辨率 refine，在 P3 生成 logits 后双线性上采样 2 倍。

训练：仅更新分割头；batch 2、960×832、SAM 审核版 Copy-Paste 概率 0.3、AdamW 初始学习率 1e-4、最多 30 epoch、耐心 10；每轮以验证集分割 IoU 选权重。

质量门槛沿用 P02：相对 B1，mAP50-95 下降 ≤0.005，person AP 下降 ≤0.003，分割 IoU 下降 ≤0.002。速度目标为同口径端到端延迟下降 ≥20%，未达到时如实记录。

各组目录包含初始化权重、逐轮训练日志、最佳权重、验证指标、配对速度和固定样本图。本轮仅使用验证集，测试集不参与结构选择。

## 完成结果与选择

H1 训练 27 epoch、最佳第 17 epoch；H2 训练 24 epoch、最佳第 14 epoch，均由连续 10 epoch 无 IoU 提升触发早停。两个检测分支完全冻结，因此验证集 mAP50-95 和 person AP 与 B1 完全相同。完整验证指标见各组 `val_metrics.json`。

| 指标 | B1 | H1 | H2 |
| --- | ---: | ---: | ---: |
| 参数量 | 10.00M | 9.61M | 9.84M |
| 计算量 | 31.89 GMACs | 24.04 GMACs | 23.68 GMACs |
| 验证分割 IoU | 0.99425 | 0.99465 | 0.99444 |
| 配对基线/候选延迟 | - | 3.44 / 3.16 ms | 3.43 / 3.01 ms |
| 配对加速 | - | 8.1% | 12.2% |
| 配对峰值 CUDA 分配 | - | 613 / 557 MiB | 618 / 545 MiB |

速度测量为同一 RTX 4090 上 batch 1、32 张固定验证图、模型前向加 NMS 和分割阈值处理；每组按 B1/候选交替测量三次，表中为三次均值的中位数。图像已预加载到 GPU，因此该数字不含磁盘读取、预处理和主机到 GPU 的拷贝。峰值分配量只与同组配对基线比较，不与 P01 旧会话的绝对显存值比较。原始三次结果见 [`H1 配对基准`](experiments/p02_h1_width64/paired_benchmark.json)和 [`H2 配对基准`](experiments/p02_h2_p3_output/paired_benchmark.json)。

**结论：**两组均通过质量门槛；H2 以更低的延迟成为本轮速度优先候选，权重为 [`finetuned_best.pt`](experiments/p02_h2_p3_output/finetuned_best.pt)。H1 的验证 IoU 略高、参数量更低，可作为保留 P2 细节路径的备选。两者均未达到预设的 20% 端到端加速目标，因此不能把计算量下降约 25% 等同于实际时延收益。

后续拆分测速显示，H2 分割头约 0.21 ms，占 H2 前向约 7.5%；检测网络约 2.60 ms，是主要耗时。进一步在同一进程交替测量 Conv/BN 融合后的模型：B1 从 3.45 ms 降至 3.13 ms，H2 从 3.00 ms 降至 2.67 ms，融合后的 H2 相对融合后的 B1 加速 14.7%。因此 H2 分割头已经不是主要瓶颈，下一步应优先做检测主干敏感度剪枝和 TensorRT/ONNX Runtime 后端验证。

验证集选择 H2 后，只对 H2 做了一次测试集评测：检测 mAP50-95 为 0.28557，与冻结的 B1 相同；分割 IoU 为 0.99319，B1 为 0.99312。结果见 [`test_metrics.json`](experiments/p02_h2_p3_output/test_metrics.json)。当前按时序划分的数据集仍限制跨场景泛化结论。

## 收尾融合与部署导出

H2 已完成检测分支和分割 refine 分支的 Conv/BN 融合，融合后的验证指标为 mAP50-95 `0.114509`、person AP50-95 `0.018402`、分割 IoU `0.994443`；测试分割 IoU `0.993191`。同一进程交替测速的融合 B1/H2 中位延迟为 `3.141/2.680 ms`，公平加速 `14.69%`。最终文件、校验记录和复现命令见 [`FINAL_REPORT.md`](FINAL_REPORT.md)。
