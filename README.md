# PathSentry Pipeline

> **PathSentry** = Path（可行驶区域）+ Sentry（障碍物哨兵）。
> 一个**端到端（Data-to-Device）全链路**机器人感知工程：在自有双目小车上完成「数据收集 → VLM 预标注（大模型 / 微调小模型双分支）→ 模型训练 → 剪枝 → 量化 → 地平线 X5 端侧 C++ 部署」的完整产业级技术闭环。
>
> **命名约定**：仓库 `pathsentry-pipeline` · 代码命名空间 `ps::` · 模型产物前缀 `pathsentry_detseg_vX`

## 1. 任务定义

| 项目 | 内容 |
|---|---|
| 硬件 | 双目立体相机（左右目同步 RGB）+ 视觉小车 |
| 任务 A：障碍物检测 | 左目图像 → 障碍物 bbox + 类别（约 12 类长尾类别：行人、锥桶、椅腿、电线、宠物、台阶边缘、花盆、栏杆、车辆、玩具、坑洞、其他障碍物） |
| 任务 B：可行驶区域分割 | 左目图像 → 逐像素二分类（可行驶 / 不可行驶），可扩展为多类（路面 / 草地 / 边界 / 未知） |
| 端侧推理 | 仅左目 RGB 进模型；双目深度（SGBM / X5 SAE）在推理之外与 2D 检测融合得到障碍物 3D 距离 |
| 目标性能（X5 BPU） | 检测 + 分割总延迟 < 50ms（20 FPS 以上）；INT8 量化后 mAP 掉点 < 2%，mIoU 掉点 < 3%；5m 内测距误差 < 10cm |

## 2. 总体架构

```
┌────────────────────────────────────────────────────────────────────┐
│ (1) 数据层                                                          │

└──────────────┬─────────────────────────────────────────────────────┘
               ▼
┌────────────────────────────────────────────────────────────────────┐

│   分支B：微调小 VLM（Qwen2.5-VL-3B + LoRA）做低成本大规模预标注       │
│   ↓ 人工抽检 + 修正（10%~20% 抽样）→ 产出训练级标注                   │
└──────────────┬─────────────────────────────────────────────────────┘
               ▼
┌────────────────────────────────────────────────────────────────────┐
│ (3) 训练层                                                          │
│   检测：YOLOv11-s / RT-DETR；分割：YOLOv11-seg / PP-LiteSeg          │

└──────────────┬─────────────────────────────────────────────────────┘
               ▼
┌────────────────────────────────────────────────────────────────────┐
│ (4) 剪枝：Torch-Pruning 结构化通道剪枝 30%~50% + 微调恢复             │
└──────────────┬─────────────────────────────────────────────────────┘
               ▼
┌────────────────────────────────────────────────────────────────────┐
│ (5) 量化：PTQ 校准（进阶 QAT），INT8 精度验证                         │
└──────────────┬─────────────────────────────────────────────────────┘
               ▼
┌────────────────────────────────────────────────────────────────────┐
│ (6) 端侧部署：OpenExplorer(onnx→HBM) + 双目深度 → 3D 融合 → 避障      │
│    C++ 推理服务，BPU 上运行，ROS2/自定义控制接口                       │
└────────────────────────────────────────────────────────────────────┘
```

## 4. 分阶段里程碑

| 阶段 | 周期 | 交付物 | 通过标准 |
|---|---|---|---|
| M1 数据 | 2~3 周 | 开源数据就绪 + ≥5k 帧本地采集 + 类别体系 v1 | 采集覆盖 ≥6 类场景；标注抽检一致率 ≥90% |
| M2 预标注 | 2 周 | 两个分支各产出 ≥3k 帧预标注 | 与人工标注对比：检测 IoU≥0.5 命中率 ≥85%，分割 mIoU ≥70 |
| M3 训练 | 2 周 | 检测 + 分割基线模型 | 本地测试集 mAP@0.5 ≥0.60，mIoU ≥0.75 |
| M4 剪枝 | 1 周 | 剪枝模型 | mAP 掉点 ≤2%，mIoU 掉点 ≤3%，FLOPs 降 ≥35% |
| M5 量化 | 1 周 | INT8 模型 | 相对剪枝模型 mAP 掉点 ≤1% |
| M6 部署 | 2 周 | X5 上 C++ 推理 + 3D 融合 demo | 端到端 ≥20 FPS，实测测距 5m 内误差 <10cm |

## 5. 关键风险与对策

| 风险 | 对策 |
|---|---|
| VLM 分割输出 mask 边界粗糙 | mask 作为预标注仅做初始化，必须人工/几何后处理精修；或改用 SAM 以 VLM 文本提示生成 mask |
| 剪枝+量化叠加掉点超预期 | 每步独立验证；预留 QAT 联合恢复训练预算 |
| 双目深度在弱纹理草地漂移 | 评测单独覆盖草地场景；必要时融合 IMU/时序滤波 |
| 长尾类（电线/坑洞）样本极少 | 定向补采 + copy-paste 数据增广 + 困难样本回传闭环 |
