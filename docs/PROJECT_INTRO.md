# PathSentry Pipeline · 项目介绍

## 一句话介绍

**PathSentry Pipeline** 是一个面向低速移动机器人的**端到端全链路视觉感知工程**：基于自有双目视觉小车，完成从数据收集、大模型自动标注、多任务模型训练、结构化剪枝、INT8 量化，到地平线 X5 芯片端侧 C++ 实时部署的完整产业级闭环，最终在小车上实现 **障碍物检测 + 可行驶区域分割 + 双目 3D 测距** 的实时感知能力。

## 解决什么问题

割草机器人、扫地机、低速配送车等产业级机器人普遍采用"地平线 X5 类端侧芯片 + 轻量视觉模型"的量产方案，而这类场景的感知任务有三个鲜明特点：

1. **没有现成数据集**——可行驶区域、草坪边界、电线/坑洞等长尾类别必须实地采集；
2. **标注成本高**——逐像素分割标注昂贵，产业界的答案是"大模型预标注 + 小模型蒸馏放大 + 少量人工抽检"；
3. **算力与精度强约束**——模型必须经过剪枝、量化才能在 BPU 上达到 20FPS 以上，且每一步的精度损失都要被严格控制。

本项目把这三条产业主线上的一切环节完整实践了一遍，形成一个可直接复用的 Data-to-Device 工程模板。

## 技术链路

```
数据收集 ──► VLM 预标注 ──► 模型训练 ──► 剪枝 ──► 量化 ──► X5 端侧部署
(双目小车)   (大/小模型双分支)  (检测+分割双头)  (结构化)   (INT8/HBM)  (C++/BPU/3D融合)
    ▲                                                              │
    └────────────── 困难样本回传闭环（data flywheel）◄──────────────┘
```

| 阶段 | 关键技术 |
|---|---|
| 数据 | 开源数据集（RELLIS-3D/RUGD/KITTI）类别映射 + 双目实地采集（场景矩阵分层覆盖）+ 金标准测试集 |
| 预标注 | 分支 A：Qwen2.5-VL-72B grounding + SAM2 两段式出框与 mask；分支 B：Qwen2.5-VL-3B LoRA 蒸馏后低成本放大标注；两分支在同一金标准上做成本-质量对比 |
| 训练 | YOLOv11-seg 双头多任务模型（共享 backbone），开源数据预训练 + 本地域微调；多任务损失平衡（固定权重 → 网格搜索 → 不确定度加权）与梯度冲突处理（PCGrad/分阶段解耦） |
| 剪枝 | Torch-Pruning 结构化通道剪枝，迭代式"剪 8~12% + 恢复微调"，稀疏率-精度帕累托搜索 |
| 量化 | OpenExplorer PTQ 校准量化（校准集全场景覆盖 + 混合精度逐层调优），QAT 兜底 |
| 部署 | X5 BPU 推理 + SAE 硬件立体匹配深度，C++ 多线程流水线、NV12 零拷贝、框-底边深度融合出障碍物 3D 距离 |

## 项目亮点

- **全链路完整**：六个阶段环环相扣，每阶段有独立方案、达标线与验收报告，并包含产业标配的数据闭环（端侧高不确定性帧回流再训练）；
- **双分支预标注对比**：大模型冷启动 vs 小模型蒸馏放大，产出量化的成本-质量决策依据，而不是"只有一个能跑的脚本"；
- **精度红线逐级控制**：训练 mAP@0.5 ≥0.60 / mIoU ≥0.75 → 剪枝掉点 ≤2/3 点 → 量化再掉 ≤1/2 点，全程在同一份人工精标金标准上分层评测（草地/逆光/黄昏），指标不被总体均值掩盖；
- **软硬件协同**：充分利用 X5 的 BPU（检测+分割）与 SAE（双目深度）异构算力，端侧实测目标 20FPS+、5m 内测距误差 <10cm。

## 硬件与目标性能

| 项目 | 配置/指标 |
|---|---|
| 传感器 | 双目立体相机（左右目同步 RGB）+ IMU，视觉小车载体 |
| 计算平台 | 地平线 Sunrise X5（10 TOPS BPU + SAE 立体匹配加速） |
| 感知输出 | 12 类障碍物框 + 4 类可行驶区域 mask + 障碍物 3D 距离 |
| 端到端延迟 | <50ms（≥20 FPS） |
| 测距精度 | 5m 内 <10cm |
